# 📊 Daily Report AI Agent

An automated Node.js CLI-based AI Agent that generates structured daily or weekly reports based on a user-defined topic.

---

## 🧠 Project Overview

This project is a simple automation tool that:
- asks the user for a topic
- saves configuration
- generates reports automatically
- can run on a schedule (daily or weekly)

---

## ⚙️ Features

- Setup wizard (first run)
- Daily / weekly configuration
- Automatic report generation
- Saves reports as .txt files
- Scheduler using node-cron
- CLI-based tool (no UI)
